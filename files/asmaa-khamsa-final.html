الأسماء الخمسة

شرح من الصفر + القاعدة + الشروط + طريقة الحل + أمثلة سهلة وصعبة

محتويات المذكرة: 1- ما هي؟ 2- الإعراب 3- قاعدة الحفظ 4- الشروط 5- طريقة الحل 6- أمثلة سهلة 7- ذو 8- إنَّ 9- سؤال صعب 10- كان 11- الجمل الطويلة 12- الفرق 13- أصلية وفرعية 14- الخلاصة

ثانيًا: كيف تُعرب؟

الأصل: الرفع بالضمة، النصب بالفتحة، الجر بالكسرة. لكن الأسماء الخمسة تُعرب بعلامات فرعية.
الحالةالعلامةالمثال والإعراب
الرفعالواوجاء أبوك = فاعل مرفوع بالواو
النصبالألفرأيت أباك = مفعول منصوب بالألف
الجرالياءمررت بأبيك = مجرور بالياء

ثالثًا: قاعدة الحفظ

ذو = رفع: جاء ذو علمٍ | ذا = نصب: إنَّ ذا علمٍ محبوبٌ | ذي = جر: مررت بذي علمٍ

رابعًا: الشروط

1- مفردة: ليست مثنى ولا جمعًا. مثال: جاء أبو الطالب.
2- مضافة: بعدها اسم أو ضمير. جاء أبو محمد (أبو=مضاف، محمد=مضاف إليه).
3- ليست لياء المتكلم: جاء أبي ← لا تُعرب بالحروف.
4- ذو بمعنى صاحب: جاء ذو علمٍ ← صح. أما إنَّ ذا يومٌ عظيمٌ ← ذا اسم إشارة (هذا) ليست خمسة.
5- فو بدون ميم: فو ← خمسة. فم ← ليست خمسة.

خامسًا: طريقة الحل

1- الوظيفة
فاعل؟ مفعول؟ اسم إن؟ خبر كان؟ مضاف إليه؟ بعد حرف جر؟
2- الحالة
فاعل=مرفوع | اسم إن=منصوب | مفعول=منصوب | مضاف إليه=مجرور | بعد حرف جر=مجرور | خبر كان=منصوب | اسم كان=مرفوع | خبر إن=مرفوع
3- العلامة
مرفوع ← واو | منصوب ← ألف | مجرور ← ياء

سادسًا: أمثلة سهلة

جاء أبوك.
مين جاء؟ أبوك = فاعل = مرفوع = بالواو.
رأيت أباك.
مين رأيته؟ أباك = مفعول = منصوب = بالألف.
مررت بأبيك.
حرف جر الباء ← أبيك = مجرور = بالياء.

سابعًا: أمثلة ذو

جاء ذو علمٍ.
ذو = فاعل مرفوع بالواو. علمٍ = مضاف إليه.
رأيت ذا علمٍ.
ذا = مفعول منصوب بالألف.
مررت بذي علمٍ.
ذي = مجرور بالياء.

ثامنًا: مع إنَّ

إنَّ تنصب الاسم وترفع الخبر.
إنَّ ذا علمٍ محبوبٌ ← ذا = اسم إن منصوب بالألف.
وإني لذو حزنٍ ← ذو = خبر إن مرفوع بالواو.

تاسعًا: سؤال صعب

إنَّ في الأمةِ لذا همةٍ.
في الأمة = خبر إن مقدم. ذا همة = اسم إن مؤخر منصوب. إذن ذا منصوب بالألف وليس ذي.

عاشرًا: مع كان

كان ترفع الاسم وتنصب الخبر.
كان أبوك حاضرًا ← أبوك = اسم كان مرفوع بالواو.
أمسى صنيعُ أبيك مضربًا للأمثال.
صنيع = اسم أمسى مرفوع. أبيك = مضاف إليه مجرور بالياء. مضربًا = خبر أمسى منصوب. الصح أبيك.

الحادي عشر: الجمل الطويلة

لا ينهض بوطننا الحر إلا كلُّ ذي فكرٍ مستنير.
الفعل ينهض. مين؟ كلُّ ذي فكر. كلُّ = فاعل مرفوع. ذي = مضاف إليه مجرور بالياء.

الثاني عشر: ذو / ذا / ذي

مرفوعة ← ذومنصوبة ← ذامجرورة ← ذي
جاء ذو علمٍرأيت ذا علمٍمررت بذي علمٍ
